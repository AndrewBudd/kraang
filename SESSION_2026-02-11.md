## Technical Insights

### Enum Comparison in Python

**Lesson Learned**: Python enums must be the same object for direct comparison

```python
# Two different enum definitions with same values
# File A:
class PassType(Enum):
    GENERAL = "general"

# File B:
class PassType(Enum):
    GENERAL = "general"

# Comparison fails!
PassTypeA.GENERAL == PassTypeB.GENERAL  # False (different objects)
PassTypeA.GENERAL.value == PassTypeB.GENERAL.value  # True (strings match)
```

**Best Practice**:
1. Define enums once in shared module, import everywhere
2. Or compare by value when multiple definitions exist

### Architecture Consideration

**Future Improvement**: Consider refactoring to single `PassType` definition:
- Create `src/pass_types.py` with shared `PassType` enum
- Both modules import from this shared location
- Eliminates comparison issues
- Better architectural pattern

**Priority**: Low (current fix works, but would be cleaner)
